# Primex Technologies

The Primex Technologies website introduces the company and its software products, pricing models and custom solution services. It is built with Next.js, React, TypeScript and Tailwind CSS.

## Get started

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Routes

- `/` — Company homepage and product overview
- `/systems` — Systems / Softwares catalogue
- `/systems/primepos` — PrimePOS product overview
- `/systems/primeschool` — PrimeSchool product overview
- `/systems/gym-management-system` — Gym Management System product overview
- `/systems/primefit` — PrimeFit product overview
- `/about` — About Primex Technologies
- `/contact` — Demo, pricing and custom-solution enquiries
- `/privacy` and `/terms` — Privacy and service terms

The legacy `/erp` route redirects to `/systems`.

Product previews are illustrative UI compositions, not screenshots of a live product. Product availability, pricing and customisation are discussed with the Primex team through the enquiry form. Contact form submissions open a prefilled WhatsApp message for the visitor to review and send.
